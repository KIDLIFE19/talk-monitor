# AI積立くん

「迷わず、続ける。」— 毎月の積立を止めないための、答えを一つだけ返すスマホ画面のモック。

- 今月の答え（積立額・次回積立日）
- 積立を続けた月数
- BTCの直近1年チャート（1年高値との距離）
- 長期積立の順番（BTC / ETH / 銀 / 金・2017〜2023年開始の中央値）
- 余剰金の単発買い・急落アラート・積立記録への導線

`index.html` をブラウザで開くだけで表示できます（依存なし・単一ファイル）。
GitHub Pages を有効にすれば、そのまま公開URLになります。

> ※数値には見本が含まれます。利益を保証するものではありません。
